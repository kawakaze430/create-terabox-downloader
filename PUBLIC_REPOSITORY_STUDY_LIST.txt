- This is a research/inspiration inventory, NOT a list of production-ready
  download engines. Existence and GitHub metadata were checked; code security,
  licensing provenance, compliance and real downloads have NOT all been audited.
- "No license detected" means do NOT copy code without rights/permission.
  "MIT" or another metadata label still requires review of actual LICENSE,
  file-level notices and transitive dependencies.
- Do not use borrowed session cookies, untrusted demo proxies, undocumented
  endpoints or DRM/authentication/premium bypasses in our product.
- We must confirm partner authorization and per-user access scope before going
  live. Publicly shared content is not automatically free to redistribute.
- Priority P0 = feasibility/security; P1 = initial product; P2 = after core
  proof; P3 = later; HISTORY = learn from failures, not a foundation.
- Original recommendation SH20RAJ/terabox-player-chrome-extension now resolves
  to sh20raj-dump/terabox-player-chrome-extension; use the canonical owner.
- Some GitHub metadata uses NOASSERTION even when a project mentions a license.
  Treat license as unresolved until reviewed by a developer.
